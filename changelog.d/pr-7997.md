### 🐛 Bug Fixes

- `split_ext` no longer reports a lone `.` as the extension of a file name
  without a short extension (e.g. `data.parquet`), so `addurls` file name
  formats using `{_name_ext}` no longer end up with a trailing dot.  Via
  [PR #7997](https://github.com/datalad/datalad/pull/7997)
  (by [@syahra712](https://github.com/syahra712))
