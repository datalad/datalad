### 🐛 Bug Fixes

- `datalad clone` no longer fails with `IndexError` when the source is `.`,
  `./` or `..` and an explicit destination is given (`datalad clone . dest`).
  Without a destination, the default name is now `.` or `..`, so the clone is
  refused as the target exists, like `git clone`.  Fixes
  [#7889](https://github.com/datalad/datalad/issues/7889).  Via
  [PR #8002](https://github.com/datalad/datalad/pull/8002)
  (by [@syahra712](https://github.com/syahra712))
