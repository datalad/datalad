### 🐛 Bug Fixes

- Shell completion no longer fails for a value with a not yet closed quote
  (`datalad push --to "ori<TAB>`), and with argcomplete >= 3.8.0 completes
  such a value attached to its option (`--to="ori<TAB>`). The workaround for
  `--option=VALUE` completion is used only with older argcomplete.
  ([PR #8003](https://github.com/datalad/datalad/pull/8003))
  (by [@yarikoptic](https://github.com/yarikoptic))
