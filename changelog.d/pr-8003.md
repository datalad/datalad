### 🐛 Bug Fixes

- Shell completion no longer fails for a value with a not yet closed quote
  (`datalad push --to "ori<TAB>`). `datalad shell-completion` now prints the
  shell code of argcomplete itself (>= 3.0.0 is required), which completes
  natively in zsh. The workaround for `--option=VALUE` completion is used only
  with argcomplete < 3.8.0.
  ([PR #8003](https://github.com/datalad/datalad/pull/8003))
  (by [@yarikoptic](https://github.com/yarikoptic))
