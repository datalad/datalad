### 🐛 Bug Fixes

- SSH connections to a non-default port, such as an SSH tunnel to a RIA store, no longer fall back to
  port 22 and prompt for a password when the shared connection was closed meanwhile, e.g. by a concurrent
  transfer. Port, identity file and IP version are now passed on every call.
  ([PR #8011](https://github.com/datalad/datalad/pull/8011))
  (by [@bpinsard](https://github.com/bpinsard))
