### 🐛 Bug Fixes

- `update --how=reset` now works on an adjusted branch (Windows / crippled
  filesystems).  The update target was built from the adjusted branch name,
  giving a nonexistent `<remote>/adjusted/<branch>(unlocked)` ref, so the
  command aborted with "Could not determine update target".  It now resolves
  the corresponding branch, as the configured-remote code path already did.
  Fixes [#7873](https://github.com/datalad/datalad/issues/7873).  Via
  [PR #7880](https://github.com/datalad/datalad/pull/7880)
  (by [@just-meng](https://github.com/just-meng))
