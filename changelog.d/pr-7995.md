### 🐛 Bug Fixes

- A provider config whose `url_re` (or `failure_re`/`success_re`) is written
  as a multi-line value starting on the next line no longer matches every
  URL: `ensure_list_from_str()` now drops the empty items such values
  produce.  Via [PR #7995](https://github.com/datalad/datalad/pull/7995)
  (by [@syahra712](https://github.com/syahra712))
