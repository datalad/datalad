### 🚀 Enhancements and New Features

- `push` gained a `-u`/`--set-upstream` option mimicking `git push -u`.
  Used together with `--to REMOTE`, it configures `REMOTE` as the
  upstream/tracking sibling of the active branch, so that a plain
  `datalad push` (or `git push`/`git pull`) afterwards knows where to go
  without repeating `--to`.  `--set-upstream` without an unambiguous
  `--to REMOTE` is now a clear error instead of silently doing nothing
  useful.
  Fixes [#7917](https://github.com/datalad/datalad/issues/7917) via
  [PR #7917](https://github.com/datalad/datalad/pull/7917)
  (by [@yarikoptic](https://github.com/yarikoptic))
