### 🏠 Internal

- The cron-only minimum-Git CI job builds on `ubuntu-24.04`, since Git 2.31.0
  no longer compiles against `ubuntu-latest`'s libcurl.
  ([PR #7983](https://github.com/datalad/datalad/pull/7983))
  (by [@yarikoptic](https://github.com/yarikoptic))

### 🧪 Tests

- `test_producer_future_key` no longer expects `ProducerConsumer` to preserve
  the producer's order when running more than one job, which it has never
  promised.
  ([PR #7983](https://github.com/datalad/datalad/pull/7983))
  (by [@yarikoptic](https://github.com/yarikoptic))

- `test_binary_data` generates its binary payload locally instead of
  downloading a github blob page, which served HTML rather than binary data
  and made the test fail whenever github returned a 5xx.  It is also split
  into `test_binary_data_ssh` and `test_binary_data_local`, so the local
  variant runs when SSH tests are disabled.
  ([PR #7983](https://github.com/datalad/datalad/pull/7983))
  (by [@yarikoptic](https://github.com/yarikoptic))
