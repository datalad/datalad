### 🚀 Enhancements and New Features

- `run` learned `--merge REVISION` and `--merge-strategy {merge|theirs|ours}`
  to execute a command as part of merging another branch, so that the
  resulting merge commit carries the run record.  This formalizes the
  "incoming"/"incoming-processed" workflow of `datalad-crawler`, where a
  branch is *built* from a branch of pristine content by a command (e.g.
  extraction of archives), and makes such a derivation re-executable with
  `rerun`.
  [PR #7916](https://github.com/datalad/datalad/pull/7916)
  (by [@yarikoptic](https://github.com/yarikoptic))
